# Code of conduct

judgly is a small hobby project. Please be kind and patient with each other, assume good
intent, and keep discussions about the work. Harassment, insults and personal attacks are not
welcome in issues, pull requests or anywhere else in the project.

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
If something goes wrong, contact the maintainer, Timo Lassmann, through the email address on his
GitHub profile. Reports are handled privately.
